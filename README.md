# 🐟 fishFingers

[![Project Status: Active – The project has reached a stable, usable state and is being actively developed.](https://www.repostatus.org/badges/latest/active.svg)](https://www.repostatus.org/#active)

## Overview
fishFingers is a non-targeted screening prioritisation tool for high-resolution mass spectrometry data. It allows for the prediction of bioconcentration factors (BCF) in over 100 species of fish using structural fingerprints derived from tandem mass spectrometry data (MS2).

## Installation
Install the latest version from GitHub:
```
# install.packages("remotes")
remotes::install_github("drewszabo/fishFingers")
```

## Package overview

fishFingers provides:
* Automated generation of structural fingerprints from SMILES
* Import predicted fingerprints from SIRIUS CSI:FingerID
* A pre-trained machine-learning model for BCF prediction
* A simple interface for single or multiple chemicals
* Internal reference and example data stored in inst/extdata
* Development scripts and results are stored in dev/

## SMILES Instructions
The `predict_bcf()` function will accept a list of SMILES as characters. For very long lists of SMILES, this may take some time to complete the fingerprint calculations.

```
library(fishFingers)

# Example SMILES string
smiles <- c(
  "CCOC(=O)C1=CC=CC=C1",
  "CCN(CC)CCOC(=O)C1=CC=CC=C1"
)

# Predict logBCF
pred <- predict_bcf(smiles, "smiles", "Cyprinus carpio")

pred
```



## SIRIUS v6.x Instructions
Structural fingerprint posterior probabilities generated by SIRIUS CSI:FingerID v6.x are accessible from a REST API. fishFingers will use this API to find and extract the fingerprint probabilities, then use Monte Carlo simulation (n = 10,000) by default to determine the best binary values for each. These values are passed to the BCF model to make the final prediction.

### Requirements
* Compute SIRIUS (molecular formula identification) and CSI:FingerID (fingerprint prediction) for features with MS2.
* Install RSirius (`sirius-client-openAPI/client-api_r` - see instructions below)
* Run fishFingers with SIRIUS running and the relevant project open.
* **Note:** SIRIUS v5.x is no longer supported by the devs. Please upgrade to v6.x for full functionality.

### Example
```
# Install RSirius (v6.3.3)
remotes::install_github(
  repo = "sirius-ms/sirius-client-openAPI@2c983e6",
  subdir = "client-api_r/generated",
  ref = "master", build = TRUE
  ) # Using hashed commit tag has been more reproducible than version name for me.

# Run fishFingers prediction with Monte Carlo thresholding
pred <- predict_bcf("sirius", threshold = "mc", N = 10000)
```

## Applicability Domain Assessment
During BCF prediction generation, the chemical applicability domain (chemical space) of new compounds are calculated using Tanimoto similarity between the strucutral fingerprints of the target and training chemicals.

Tanimoto similarity ranges from 0 (completely dissimilar) to 1 (identical). Compounds with higher similarity scores are within the training domain and predictions are more reliable. Scores above 0.8 are annoatated as "good" similarity, and scores above 0.6 are annotated as "fair" similarity. Scores between 0.0 and 0.6 are annotated as "poor" and the predicted BCF should be interpreted with caution.

## General input requirements
* SMILES should be valid and parseable by rcdk (use `webchem::is.smiles()` to check your strings beforehand).
* SIRIUS should be running with the relevant project open. Alternatively, specify a path to the .sirius project to find fingerprints from there.
* Predictions are most reliable for chemicals within the applicability domain from the training data.
* Only species in the training and test sets are available for prediction at this time (use `fishFingers::check_species(list = TRUE)` for complete list).
* The total number of BCF observations in the training model will be included in the fishFingers output to help evaluate the applicability domain for species.

## Model details
* Target variable: log10 bioconcentration factor (BCF)
* Descriptors: binary structural fingerprints & one-hot encoded species variables
* Model type: XGBoost
* Training data size: >1000 chemicals
